# Human Use

This thematic area covers how people use linear disturbances in the boreal forest, such as seismic lines, pipelines and powerlines, and which features of a line and its surroundings make it more likely to be used. Human use, especially by off-highway vehicles (OHVs), keeps lines compacted and open. That slows vegetation recovery and changes how wildlife use the landscape, so it is a key factor in BERA's assessment of line recovery.
