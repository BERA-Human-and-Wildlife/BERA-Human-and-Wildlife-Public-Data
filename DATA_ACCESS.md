# Data access

## Access levels

| Level | What it means | Datasets |
|---|---|---|
| ✅ **Open** | The data, code and documentation are in this repository. Anyone can use them under the stated licence. | `small_mammals/Franceschini_linear_feature_width/`, `small_mammals/Franceschini_seismic_line_recovery/` |
| 🔒 **On request (until published)** | Only the description is public. Access is subject to the [Terms of Use](TERMS_OF_USE.md). The data become open once the study is published. | `human_use/Saini_OHV_seismic_lines/` |
| 🔒 **On request** | Only the description is public. Access needs the data owner's approval and is subject to the [Terms of Use](TERMS_OF_USE.md). | `birds/Kalukapuge_birds_linear_features/` |

## How to request access

Email **afrances@ualberta.ca** with the subject line **"BERA data request – <dataset folder>"**, and include:

1. your name, position and affiliation;
2. the dataset(s) you need;
3. the purpose of the request (e.g. a research question, a collaboration, or a meta-analysis);
4. whether you plan to publish results from the data, and with whom.

## What happens next

1. Your request is passed to the owner of the dataset.
2. If it is approved, you'll be asked to confirm by email that you accept the [Terms of Use for Restricted Data](TERMS_OF_USE.md). In short: use for the approved purpose only, no redistribution, non-commercial use, cite the data, and discuss co-authorship with the data owner.
3. You are then invited to the [BERA-Human-and-Wildlife](https://github.com/BERA-Human-and-Wildlife) organization on GitHub, with **read-only** access to the private repository `BERA-Human-and-Wildlife-Restricted-Data`. You need a GitHub account (a free one is fine). Accept the invitation within 7 days.
4. Access can be withdrawn at any time. When your project ends, stop using the data and delete your copies.
