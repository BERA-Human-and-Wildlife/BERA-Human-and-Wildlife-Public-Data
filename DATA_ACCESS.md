# Data access

## Access levels

| Level | What it means | Datasets |
|---|---|---|
| ✅ **Open** | The data, code and documentation are in this repository. Anyone can use them under the stated licence. | `small_mammals/Franceschini_linear_feature_width/` |
| 🔒 **On request (until published)** | Only the description is public. The data become open once the study is published. | `human_use/Saini_OHV_seismic_lines/`, `small_mammals/Franceschini_seismic_line_restoration/` |
| 🔒 **On request** | Only the description is public. Access needs the data owner's approval. | `birds/Kalukapuge_birds_linear_features/` |

## How to request access

Email **afrances@ualberta.ca** with the subject line **"BERA data request – <dataset folder>"**, and include:

1. your name, position and affiliation;
2. the dataset(s) you need;
3. the purpose of the request (e.g. a research question, a collaboration, or a meta-analysis);
4. whether you plan to publish results from the data, and with whom.

## What happens next

1. Your request is passed to the owner of the dataset.
2. If it is approved, you are invited to the private data repository on GitHub. You need a GitHub account; a free one is fine. Accept the invitation within 7 days.
3. Approved data are shared for the purpose stated in your request. Do not redistribute them. Cite the project as given in its README, and discuss co-authorship with the data owner where appropriate.
